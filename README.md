# 🎣 Simple Fishing

A small 2D relaxing fishing game about catching fish by the lake.

You are a wizard with a fishing rod. Cast your line, wait for a bite, and try to bring different fish back to shore.

🐟 **Four different fish**

🎣 **Simple fishing minigame**

💪 **Stamina-based reeling**

🌲 **A quiet lakeside environment**

## 🎮 Gameplay

The game follows a simple loop:

**Cast → Wait → Fish bites → Reel → Catch**

Each fish has its own behaviour. Some move slowly, some move quickly, and some behave in unusual ways.

Your goal is to catch all four fish and discover what they look like and what makes each of them different.

## 🕹️ Controls

| Key                         | Action                      |
| --------------------------- | --------------------------- |
| `Left Mouse Button`         | Interact / charge your cast |
| `Release Left Mouse Button` | Cast the fishing rod        |
| `Space`                     | Reel in the fish            |
| `Collection`                | View discovered fish        |

## 🎯 Project Goal

This game was created as a **small solo development project**.

The main goal was to practice taking a game from an initial idea through development, balancing, polish and public release.

During development, I experimented with:

* state-based gameplay systems;
* resource-based fish data and behaviours;
* collision-based fishing boundaries;
* a simple fishing minigame;
* separating gameplay logic from UI;
* working with a strict time limit;
* balancing a mechanic through iteration rather than trying to calculate the perfect values beforehand.

The project was intentionally kept small so that it could reach a finished and publishable state.

## 📅 Development

**Start:** September 2, 2026
**Finished:** September 8, 2026

The project was planned as a small one-week game.

The initial concept was more ambitious, but the scope was deliberately reduced during development to keep the core fishing experience manageable and finish the project within the available time.
